Hotel images structure (Option A)
=================================

For each hotel, place a single cover image and optional public area photos:

- /images/hotels/<hotel-slug>/cover.jpg        ← main card/cover image
- /images/hotels/<hotel-slug>/public/          ← optional public/common area images

Hotel slugs used in this project:
- aldeita-mixteca
- la-otra-aldeita
- la-arbolita
- nido-escondido
- casa-yahua
- casa-guadalupe
- casa-oaxira
- coco-by-the-beach
- ranchito-zicatela
- espacio-malinxhe

Notes:
- Use web‑optimized JPG/WEBP ~1600px wide
- Keep names lowercase, kebab‑case
- After adding files, access them via /images/hotels/<slug>/cover.jpg
